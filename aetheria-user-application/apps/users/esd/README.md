# Embedded System Design reference course

The embedded ESD application is sourced from:

- Repository: `https://github.com/mrithulavj/ESD1.git`
- Reviewed revision: `b05438e88b95ca1c40b03bd8d68fb4ad865ab734`
- Course: Embedded System Design

The reviewed source is retained in the repository-level `ESD1` folder. The
host build verifies every retained source file against `source-integrity.json`
before producing the same-origin static application in `public/ESD1`.

The course is adapted to the Beyond Syllabus module flow without changing its
five case studies, unit order, concepts, hardware explanations, checkpoints,
what-if labs, or simulators:

1. `?unit=1` through `?unit=5` locks the selected unit and removes unrelated
   unit switching controls.
2. The embedded header follows the same white-and-blue navigation language as
   the OOPJ and Computer Networks modules.
3. Section buttons jump directly to the story, architecture, concepts,
   simulator, checkpoint, and what-if lab.
4. Learn for a Test uses 78 source-backed cards generated from the repository's
   curriculum and interactive checkpoints. No separate official question-bank
   document was present in the supplied repository.
5. The full-screen action opens the selected unit directly on Beyond Syllabus.
