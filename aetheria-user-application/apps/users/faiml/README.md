# Fundamentals of Artificial Intelligence and Machine Learning reference course

The embedded FAIML application is sourced from:

- Repository: `https://github.com/mrithulavj/faiml.git`
- Course: `2311CSC303J Fundamentals of Artificial Intelligence and Machine Learning`
- Syllabus: `Regulations R2023_V1.2`

The source is retained in the repository-level `faiml` folder. The host tooling builds and syncs the same-origin static application to `public/FAIML`.

The retained course content is adapted for the Beyond Syllabus module flow:

1. `?unit=1` through `?unit=5` locks the selected unit, opens its detailed simulator first, and removes unrelated unit controls.
2. The embedded shell uses the same Beyond Syllabus slate-and-navy course theme and navigation model as the OOPJ and Computer Networks units, with all SynapseAI branding removed.
3. The concept map is improvised with a clean panoramic light-mode canvas, architectural lanes, smooth SVG curves, live keyword/Bloom search, and deep-dive concept modals with direct simulator triggers.
4. The question bank view presents all 125 official syllabus questions (15 Part A, 8 Part B, 2 Part C per unit) scoped to the active unit with model answers, formulas, comparison tables, rubrics, and the unit assessment quiz.
5. All 14 interactive algorithm laboratories and 5 real-world case studies are organized unit-by-unit rather than being presented all in one screen.
6. The host application's full-screen action opens the selected unit directly on Beyond Syllabus.
